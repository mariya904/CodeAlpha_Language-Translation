# CodeAlpha_LanguageTranslator

AI Internship Task 1 – Language Translation Tool (CodeAlpha).

## Features
- Enter text, pick source (or auto-detect) and target language
- Translation via Google Translate (`deep-translator`, no API key needed)
- Swap languages button
- One-click copy (hover over the result box) and text-to-speech (gTTS)

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Tech
Python, Streamlit, deep-translator, gTTS
